# Conhecendo as Escrituras — Blueprint UX/UI V2

## Objetivo

Redesenhar o site original como uma landing page de aquisição para GitHub Pages, preservando as informações reais do produto e reorganizando sua apresentação para melhorar clareza, confiança, experiência e conversão.

## Princípios

1. Resultado percebido antes da lista de conteúdo.
2. Problema → desejo → solução → confiança → oferta → decisão.
3. Cada seção deve cumprir uma função concreta na jornada.
4. Conteúdo real primeiro; nenhum depoimento, credencial, garantia, preço ou número pode ser inventado.
5. Design editorial contemporâneo, evitando estética genérica de infoproduto.
6. Interface simples; profundidade no conteúdo, não na complexidade da navegação.
7. Mobile e acessibilidade são requisitos desde a implementação inicial.

## Direção visual

- Base: marfim/off-white e tons de papel.
- Texto principal: carvão quase preto.
- Acento: amarelo associado à identidade atual.
- Títulos: serif contemporânea.
- Interface e texto de apoio: sans-serif limpa.
- Componentes: bordas discretas, cantos moderados, pouco ruído visual.
- Recursos gráficos: linhas, mapas conceituais, timelines e relações entre elementos.
- Fotografia real do autor quando disponível.

## Critérios de revisão antes de considerar a página pronta

### Conteúdo
- Não há informação factual sem origem conhecida.
- A proposta de valor é entendida sem ler a página inteira.
- O usuário consegue distinguir método, conteúdo e resultado.

### UX
- A próxima ação é clara em cada estágio de intenção.
- Navegação por âncoras funciona.
- Accordions e detalhes não escondem informação essencial.
- Foco de teclado é visível.
- Layout não depende de hover.

### UI
- Hierarquia tipográfica consistente.
- Espaçamento ritmado.
- Contraste adequado.
- CTA visualmente prioritário sem dominar a página.
- Seções formam uma narrativa contínua, não uma coleção de cards.

### Responsividade
- Desktop, tablet e celular preservam a hierarquia.
- Componentes complexos possuem versão empilhada funcional.
- Nenhum elemento essencial exige zoom ou rolagem horizontal.

### Conversão
- Hero comunica resultado + mecanismo + próximo passo.
- Oferta deixa preço, parcelamento, acesso e próxima ação claros.
- Objeções relevantes são respondidas antes do CTA final.
- Prova social só aparece quando houver material real.
